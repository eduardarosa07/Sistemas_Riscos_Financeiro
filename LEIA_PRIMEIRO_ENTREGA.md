# SGR — Entrega para execução e homologação

**Base usada:** `Sistemas_Riscos_Financeiros(2).zip`.

Este é um pacote de **código revisado e testes para executar**, não uma afirmação de que 86 requisitos foram homologados. Não há dump PostgreSQL no ZIP original nem acesso a dependências Spring para realizar os testes completos aqui.

**Leia primeiro:** `docs/RELATORIO_VALIDACAO.md` e `docs/GUIA_EXECUCAO_WINDOWS.md`.

**Executar no Windows:** instalar Node e Java 21, configurar PostgreSQL, depois usar `./scripts/validar_local.ps1` no PowerShell.

**Catálogo:** `docs/MATRIZ_86_REQUISITOS.csv` contém todos os 86 requisitos, sem exclusões, e indica as evidências necessárias para aceite.

**Não alterei a identidade visual geral do Angular:** CSS, shell e layout principal existentes foram preservados. Há apenas acréscimos funcionais nas telas originais.
